# Changelog

## 2.0.0 — 2026-10-17

- Unified the Singularity palette, approved Spacetime Desktop 4.0.0 animation,
  secure lock presentation, idle/screensaver integration, Plymouth and SDDM
  artwork into the existing theme repository.
- Included the accepted emerald toolbar, violet clock/workspace accents,
  Rajdhani clock and popup titles, outlined workspace numbers, monochrome
  Bitwarden shield, blue descriptions, orange selections and 90% popup/menu/
  launcher/tooltip/notification backgrounds.
- Carried the toolbar palette into GTK3/libadwaita applications and btop, added
  88 original SVG folder/file/device icons, and matched utility window opacity.
- Included the accepted 90%/88% Codex/Work window opacity rule as a small include.
- Retained native authentication, presentation-only password dots, bounded dot
  drawing and the hardened boot backup/recovery implementation.
- Added one complete installer/update command, private copied runtime,
  source checksums, deterministic release packaging and user-desktop rollback.
- Removed host-specific executable paths and private plugin names from payloads;
  migrated earlier `simp.*` and `spacetime.background` installations.
- Preserved the standard Omarchy theme installer for palette-only use.

The animation itself remains the approved five-route, 450-second native mesh.
Earlier static theme and standalone animation repositories remain compatible
entry points; complete Singularity updates are now maintained here.
